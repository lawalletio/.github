### ⚡ LaWallet NWC — core platform

Lightning Address platform + Nostr CRM, connected via Nostr Wallet Connect. &nbsp;[`lawallet-nwc`](https://github.com/lawalletio/lawallet-nwc)

| Component      | Description                                         | Repo                                                                                  | Live                                         |
| :------------- | :-------------------------------------------------- | :------------------------------------------------------------------------------------ | :------------------------------------------- |
| **Web app**    | Admin dashboard + user wallet (Next.js)             | [`apps/web`](https://github.com/lawalletio/lawallet-nwc/tree/main/apps/web)           | [beta.lawallet.io](https://beta.lawallet.io) |
| **Listener**   | Nostr / Lightning background event listener         | [`apps/listener`](https://github.com/lawalletio/lawallet-nwc/tree/main/apps/listener) | —                                            |
| **Umbrel app** | One-click self-host on [Umbrel](https://umbrel.com) | [`umbrel-app-store`](https://github.com/lawalletio/umbrel-app-store)                  | —                                            |
| **Start9 app** | Service package for [StartOS](https://start9.com)   | [`lawallet-startos`](https://github.com/lawalletio/lawallet-startos)                  | —                                            |
